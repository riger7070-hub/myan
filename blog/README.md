# 블로그에 올릴 글

네이버 블로그를 기준으로 쓴다. 사주를 찾아보는 사람은 네이버에서 찾는다.

## ⚠️ 반드시 지킬 것

**웹페이지 글을 그대로 옮기지 않는다.**
같은 글이 두 주소에 있으면 검색이 둘 중 하나를 중복으로 보고 낮춘다. 우리 페이지가
밀리면 본전도 못 찾는다. 역할을 나눈다.

    블로그   왜 그런지 설명하는 글
    페이지   계산해 주는 도구

블로그에서 설명하고 페이지로 보낸다. 반대로 하지 않는다.

**키워드를 억지로 반복하지 않는다.**
제목에 한 번, 본문에 자연스럽게 두세 번이면 된다. 그 이상은 사람이 읽기 싫어지고
검색도 좋아하지 않는다. 예전 방식이다.

**한 글을 여러 블로그에 붙여 넣지 않는다.**
그것도 중복이다. 하나만 고르거나, 고쳐 써서 올린다.

**그림은 그 글에 맞는 것으로.**
손 없는 날 글에 궁합표를 넣지 않는다. 해당 페이지를 캡처해 쓰는 것이 가장 낫다.

## 올리는 간격

한 주에 하나면 충분하다. 몰아서 세 개를 올리면 홍보 계정으로 읽힌다.
댓글이 달리면 성실히 답한다. 그게 다음 글의 신뢰가 된다.

## 결과 보는 법

검색에 잡히기까지 1~3주 걸린다. 다음 날 확인해 봐야 아무것도 없다.
어디서 들어오는지는 아래로 본다.

    npm run smoke                     배포본이 멀쩡한지
    /admin/hits                       무료 페이지별 유입 (ref 로 갈린다)
