# 네이버 블로그에 올릴 글

`.txt` 세 개가 **붙여 넣는 글**이다. 열어서 전부 복사해 편집기에 붙이면 끝난다.
기호가 하나도 없다. 우물정도 별표도 가운뎃점도 따옴표도 없다.

⚠️ 확장자가 `.md` 가 아니라 `.txt` 인 이유: md 로 두면 다음에 고칠 때 무심코
   마크다운을 다시 쓰게 된다. **붙여 넣는 글에는 문법이 없다**는 뜻을 확장자로 남긴다.
   `test/blog-plaintext.test.mjs` 가 기호가 다시 섞이면 잡는다.

## 프로필 사진

 는 **
> myan-web@1.0.0 blog
> node tools/build-blog-page.mjs

blog/blog-page.html  2231KB  (글 3편) 이 insta/profile.png 에서 복사해 온다.**
손으로 옮겨 두지 않는다 — 두 벌을 손으로 관리하면 원본을 고치고 이쪽을 잊는다.
그래서 커밋하지 않는다(.gitignore).

⚠️ 인스타·X 와 **같은 그림**을 쓴다. 계정마다 얼굴이 다르면 같은 곳이라는 것을
   알아보지 못한다. 글씨가 없고 모서리가 비어 있어 동그랗게 잘려도 괜찮다.

## 사진 넣는 자리

글 안에 `사진 넣는 자리 하나` `사진 넣는 자리 둘` 이라고 적어 두었다.
그 줄을 지우고 아래 그림을 넣으면 된다.

| 글 | 사진 하나 | 사진 둘 |
|---|---|---|
| 손없는날.txt | `insta/sonnal.png` | 손 없는 날 페이지를 캡처 |
| 띠궁합.txt | `insta/gunghap.png` | 궁합표 페이지를 캡처 |
| 만세력.txt | `insta/manseryeok.png` | 만세력에 실제로 넣어 본 결과를 캡처 |

⚠️ **두 번째 사진은 직접 캡처한다.** 카드만 두 장 넣으면 광고로 보인다. 실제 화면이
   한 장 있어야 "쓸 수 있는 것" 으로 읽힌다. 만세력은 본인 생년월일 말고 아무 날짜나
   넣어서 찍을 것.

## 제목과 태그

제목은 글 첫 줄을 그대로 쓰면 된다.

태그는 **글 안에 이미 들어 있다.** 맨 끝 줄이 태그 줄이다. 우물정을 붙여 두었으니
본문째로 붙여 넣으면 네이버가 알아서 태그로 잡는다. 따로 옮겨 적지 않아도 된다.

## 문단 나누기

소제목 앞에 ▍를 붙여 두었다. 마크다운 우물정은 편집기에 그대로 찍히므로 안 쓴다.
큰 단락 사이는 가로줄로 갈랐다. 편집기에서 그 줄을 지우고 구분선을 넣어도 좋다.

## 인사말

**첫 글(손없는날)에만** 인사와 맺음말이 들어 있다. 오랜만에 여는 블로그라서다.
나머지 둘에는 없다 — 매번 인사하면 늘 처음 온 사람에게 말하는 꼴이 된다.

## ⚠️ 반드시 지킬 것

**웹페이지 글을 그대로 옮기지 않는다.**
같은 글이 두 주소에 있으면 검색이 둘 중 하나를 중복으로 보고 낮춘다. 우리 페이지가
밀리면 본전도 못 찾는다. 역할을 나눈다.

    블로그   왜 그런지 설명하는 글
    페이지   계산해 주는 도구

**한 글을 여러 블로그에 붙여 넣지 않는다.** 그것도 중복이다.

**한 주에 하나씩.** 세 개를 몰아 올리면 홍보 계정으로 읽힌다.
댓글이 달리면 성실히 답한다. 그게 다음 글의 신뢰가 된다.

## 순서

손없는날을 먼저 올린다. 셋 중 검색량이 가장 크고, 가을 이사철이 다가온다.

    npm run smoke     배포본이 멀쩡한지
    /admin/hits       무료 페이지별 유입 (ref 로 갈린다)
