# 홍보 기록

아침 홍보 대장(`npm run promo`)이 **이 파일을 읽어서** 오늘 할 일을 정한다.
[docs/홍보.md](../docs/홍보.md) 가 "무엇을 어떻게 쓸까" 라면, 여기는 "어디까지 했나" 다.

⚠️ **줄 모양을 바꾸지 말 것.** `tools/build-promo-page.mjs` 가 아래 두 모양만 읽는다.

    - [ ] 이름 | 주소 | 막힌 자리 (없으면 비운다)
    - [x] 2026-08-30 이름 | 주소 | 남길 말

`[ ]` 는 아직, `[x]` 는 올렸다는 뜻이다. 올린 날은 **반드시 `YYYY-MM-DD`** 로
적는다 — "어제", "지난주" 는 며칠만 지나면 거짓말이 된다.

## ⚠️ 브라우저로 글자를 칠 때

내가 브라우저에 글을 직접 치면 **한글 몇 글자가 조용히 망가진다.**
오류도 경고도 없고, 올라간 뒤에야 보인다. 2026-09-01 에 둘 잡았다.

    잇  →  ㅅ 받침이 ㅇ 으로 바뀐다     ("그 뒤를 잇습니다" → "잉습니다")
    뒤  →  글자가 통째로 사라진다        ("그 뒤예요" → "그  예요")

⚠️ 그래서 **올리기 전에 입력칸을 통째로 다시 읽어 원고와 맞춰 본다.** 화면을
눈으로 훑는 것만으로는 모자란다 — 글자가 하나 빠져도 문장이 그럴듯하게 남는다.

망가지는 글자가 나오면 **그 줄을 다른 말로 바꾸거나 뺀다.** 무엇이 망가질지
미리 알 길이 없으니, 같은 글자를 여러 번 치며 싸우지 않는다.

## 날마다 하던 일은 멈췄다 (2026-09-15)

사장님이 「블로그 붙여넣기랑 인스타·스레드 글쓰는 거 매일 하지 마라」 하셨다.
셋 다 껐다. **지운 게 아니라 꺼 둔 것이라** 한마디면 되살아난다.

    AnsikBlogMorning   평일 08:15   블로그 붙여넣기 대장   → Disabled
    AnsikPromoDaily    날마다 08:45  홍보 대장             → Disabled
    trig_01Hf5CYG...   평일 새벽     블로그 초안 쓰기       → enabled:false

⚠️ 내가 날마다 올리던 인스타·X 도 멈춘다. 이제 **말씀하실 때만** 올린다.

⚠️ 아래 「한 번만 올리는 곳」은 그대로 남는다. 커뮤니티는 원래 날마다 하는
일이 아니었고, 로그인이 풀리면 그때 한 곳씩 올리면 된다.
