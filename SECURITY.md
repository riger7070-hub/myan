## Reporting a Vulnerability

**Please do not open public issues for security vulnerabilities.**

If you discover a security vulnerability within this project, please send an e-mail to [security@yourdomain.com](mailto:security@yourdomain.com). All security vulnerabilities will be promptly addressed.

### Our Process

1. **Acknowledgment:** You will receive an acknowledgment of your report within 48 hours.
2. **Investigation:** We will investigate the issue and determine the potential impact.
3. **Fix & Release:** If validated, we will work on a fix and release a patched version as soon as possible.
4. **Disclosure:** We practice Coordinated Vulnerability Disclosure. We ask that you do not disclose the vulnerability publicly until a patch is available.

### Credits
We deeply appreciate the community's help in keeping this project secure. Valiant researchers who responsibly disclose vulnerabilities will be credited in our release notes.
