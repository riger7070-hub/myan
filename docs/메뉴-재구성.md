# 메뉴 재구성 — 미니앱은 끝, 웹은 남음

2026-08-31 작업. **미니앱만 바꿨다. 웹은 그대로다.**
집에서 이어서 하시려면 이 문서만 보면 된다.

---

## 왜 바꿨나

메뉴가 31가지였는데 **축이 셋으로 섞여 있었다.**

- 어떤 칸은 **주제**로 나뉘고 (사주로 보는 나 / 궁합과 인연)
- 어떤 칸은 **시간**으로 나뉘고 (오늘의 운세 / 때와 방위)
- 어떤 칸은 **도구**로 나뉘었다 (물어보는 점 — 타로·주역·룬)

그래서 같은 물음이 여러 칸에 흩어졌다.

- **"오늘 어때?" 를 묻는 칸이 다섯** — 오늘의 운세 / 띠 순위 / 띠와 별자리 / 주제별 / 행성
- **"이거 어떻게 될까?" 가 넷** — 타로 / 주역 / 룬 / 꿈해몽
- **돈 얘기가 세 군데** — 재물 / 직업 / 대운

다섯 칸이 전부 1엽전이었다. 값이 같으니 **무엇이 다른지 알 방법이 없었다.**

## 어떤 축으로 바꿨나

**누가 풀어 주는가(캐릭터).** 이미 콘텐츠마다 맡은 사람이 정해져 있었다
(`FEATURE_SPEAKER`). 하나는 정확히 한 사람에게 속하고(중복 없음), 넷이 전부를
덮는다(빠짐없음). 새로 만든 축이 아니라 **이미 있던 것을 쓴 것**이다.

| 묶음 | 칸 | 담긴 것 |
|---|---|---|
| **안도령 — 기운을 읽다** | 7 | 내 사주 풀이(무료) · 돈이 모이는 자리 · 이 길이 내 길이 맞을까 · 지금 나는 어느 10년 · **오늘 어때요** · **뽑아서 보기** · **이름·얼굴·숫자로 보는 나** |
| **안낭자 — 인연을 보다** | 5 | 이 사람과 좋은 때 · 속궁합 · 왜 자꾸 어긋날까 · 내 짝은 어떤 사람 · 오행으로 보는 두 사람 |
| **안할매 — 액을 눅이다** | 5 | 내 사주에 앉은 살 · 토정비결 · 올해 나에게 오는 것 · 전생 · **물어보기** |
| **안동자 — 길한 것을 찾다** | 5 | 누가 나를 도와줄까 · 나에게 좋은 방향 · 이 일에 좋은 날 · 오늘의 행운 아이템 · 산가지 뽑기 |

**타일 30개 → 22개.** 콘텐츠는 하나도 안 없앴다.

## 합친 칸 넷 (굵게 표시한 것)

누르면 **「무엇으로 볼까요」 화면**이 뜨고 거기서 고른다. 고른 뒤에는 그 콘텐츠의
평소 길로 간다(입력이 필요하면 입력 화면까지).

| 합친 칸 | 품고 있는 것 | 값 |
|---|---|---|
| 오늘 어때요 | 사주로 보는 오늘 · 띠 순위 · 띠와 별자리 · 주제를 골라서 · 행성으로 | 1 |
| 뽑아서 보기 | 타로 카드 · 룬 문자 | 1 |
| 물어보기 | 주역으로 묻다 · 꿈해몽 | 1 |
| 이름·얼굴·숫자로 보는 나 | 내 이름 · 아이 이름 · 관상과 손금 · 숫자로 보는 성향 | 4·4·4·2 |

⚠️ 마지막 칸은 **값이 저마다 다르다.** 그래서 고르는 화면에 칸마다 값을 적어 뒀다.
타일에 적힌 4엽전만 믿고 들어온 사람이 2엽전을 보면 그건 괜찮지만, 그 반대는
속은 기분이 든다.

## 화자를 옮긴 것 셋

묶음을 바꾸면서 **맡은 사람도 바뀐 콘텐츠**가 셋이다. 이건 화면만이 아니라 글의
말투가 바뀌는 일이다.

| 콘텐츠 | 전 | 후 | 왜 |
|---|---|---|---|
| 나에게 좋은 방향 | 안할매 | **안동자** | 좋은 방향을 찾는 것은 길한 것을 찾는 일 |
| 이 일에 좋은 날 | 안할매 | **안동자** | 위와 같다 |
| 올해 나에게 오는 것 | (없음, 기본 안도령) | **안할매** | 토정비결과 같은 "한 해 운" |

⚠️ 화자 표는 **세 곳**에 있고 셋이 글자까지 같아야 한다.
`mini/src/contents.js` · `worker.js` · `js/app.js`
게다가 **핸들러가 실제로 그 화자로 부르는지**는 또 다른 문제다. 이번에도
`contents.js` 만 고쳤다가 `worker.js` 의 핸들러가 계속 안할매로 부르고 있었다.
`test/speakers.test.mjs` 가 넷을 다 대조한다.

## 무엇을 고쳤나 (파일별)

### `mini/src/contents.js`
- `SECTIONS` 를 캐릭터 넷으로 다시 짬. 제목에 사람 이름이 들어감
- **`PICKED` 배열 새로 만듦** — 합친 칸이 품고 있는 실제 콘텐츠들.
  홈 타일로는 안 보이지만 `itemById` 로 찾을 수 있어야 한다
- `ALL_ITEMS = [...SECTIONS.flatMap(...), ...PICKED]` 로 바꿈
- `pickedOf(item)` 추가 — 고르는 화면이 목록을 그릴 때 쓴다
- `FEATURE_SPEAKER` 에서 direction·auspicious-days 를 dongja 로, year-luck 을 halmae 로

### `mini/src/main.js`
- `openItem` 에 `if (item.pick) { go('pick'); return; }` 한 줄
- `case 'pick':` 화면 새로 만듦 (타일 목록 + 돌아가기)
- `pickedOf` 를 가져옴

### `worker.js`
- `FEATURE_SPEAKER` 를 위와 같이 고침
- `handleDirection` · `handleAuspiciousDays` 의 `geminiText` 호출을 `speaker: 'dongja'` 로
- `handleYearLuck` 에 `speaker: 'halmae'` 를 **새로 넣음** (전에는 화자를 안 넘겼다)

### `js/app.js`
- `_FEATURE_SPEAKER` 만 위와 같이 고침. **묶음(`_homeSections`)은 안 건드렸다**

### 시험
- `test/menu-by-speaker.test.mjs` **새로 만듦** — 묶음과 화자 표가 어긋나면 잡는다
- `test/client-sections-sync.test.mjs` — 웹·미니앱 제목 대조를 **한시적으로 건너뜀**.
  `웹옮김완료 = false` 를 `true` 로 바꾸면 다시 켜진다.
  ⚠️ 건너뛴 시험은 잊히므로, **웹이 캐릭터 묶음으로 바뀐 것을 코드로 알아채면
  자물쇠를 안 풀었다고 실패시키는 시험**을 함께 넣었다

## 웹에 옮길 때 (남은 일)

### 왜 아직 못 했나
웹에는 **합친 칸을 여는 「고르기」 화면이 없다.** 그대로 캐릭터로만 묶으면
**안도령 칸이 열다섯 개**가 된다 — 웹에는 미니앱에 없는 로또·오늘의 행운도 있다.
한 묶음 7개 규칙(`test/home-sections.test.mjs`)에 걸린다.

### 순서
1. **웹에 고르기 화면을 만든다.** 미니앱의 `case 'pick':` 이 본보기다.
   웹은 모달을 쓰므로 `openPickModal(items)` 쯤이 되겠다
2. `js/app.js` 의 `_homeSections()` 를 캐릭터 넷으로 다시 짠다.
   제목·아이콘·순서를 미니앱과 **글자까지 같게** 맞춘다
3. 웹에만 있는 둘을 어디에 넣을지 정한다
   - **오늘의 로또번호** — 안동자(길한 것을 찾는다)가 맞아 보인다
   - **오늘의 행운**(무료) — 같은 자리
4. `test/client-sections-sync.test.mjs` 의 `웹옮김완료` 를 **`true`** 로 바꾼다
5. `npm test` — 건너뛰던 두 시험이 살아나 제목·아이콘을 대조한다

### 옮길 때 조심할 것
⚠️ 웹의 항목은 `path` 가 아니라 `fn:'openWealth()'` 로 되어 있다. 미니앱과 항목이
**완전히 같지는 않다**(로또는 웹에만, 출석·산가지는 미니앱에만). 시험도 제목과
아이콘만 대조하지 항목까지 보지 않는다.

⚠️ 웹 묶음을 고치면 `test/home-sections.test.mjs` 의 2~7 규칙과 값 대조표
(`HANDLER_OF`)도 함께 본다.
