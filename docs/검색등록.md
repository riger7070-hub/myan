# 검색 등록 (구글 · 네이버)

무료 페이지를 만들어 둬도 검색에 걸리지 않으면 아무도 오지 않는다.
아래는 한 번만 하면 되는 일이다. 20분쯤 걸린다.

> **진행 상태 (2026-08-23)**
>
> - 구글: 등록 완료. URL 접두어 속성 + HTML 파일 방식으로 소유 확인했고,
>   사이트맵도 제출했다. `wrangler.toml` 의 `GOOGLE_VERIFY` 가 그 파일 이름이다.
>   제출 직후 상태가 "가져올 수 없음" 으로 뜨는데, 사이트맵 자체는 200 으로
>   정상 응답한다 — 구글이 아직 안 가져간 것이라 하루쯤 뒤 다시 볼 것.
> - 네이버: 아직. 아래 1번이 그대로 남아 있다.


**네이버를 먼저 하는 편이 낫다.** 사주·운세·삼재 같은 말은 국내에서 네이버로
찾는 사람이 훨씬 많다.

---

## 준비돼 있는 것

이미 서버에 올라가 있다. 따로 만들 것이 없다.

| 주소 | 무엇인가 |
|---|---|
| `https://myan.riger7070.workers.dev/sitemap.xml` | 검색엔진에게 보여 줄 페이지 목록 |
| `https://myan.riger7070.workers.dev/robots.txt` | 어디를 보고 어디를 보지 말지 |

`robots.txt` 는 `/i/`(궁합 초대)를 막아 둔다. 남의 생년월일을 받는 자리라
검색에 걸리면 안 된다.

## 1. 네이버 서치어드바이저

1. <https://searchadvisor.naver.com> 접속 → 네이버 계정으로 로그인
2. 오른쪽 위 **웹마스터 도구** → **사이트 등록**
3. `https://myan.riger7070.workers.dev` 입력 후 등록

### 소유 확인

**HTML 파일 업로드** 방식을 고른다. `naver1a2b3c4d.html` 같은 파일 이름이 나온다.
**파일을 내려받을 필요 없다.** 이름만 복사해서 아래처럼 넣으면 된다.

`wrangler.toml` 의 `[vars]` 밑에 한 줄 추가:

```toml
NAVER_VERIFY = "naver1a2b3c4d.html"
```

그리고 배포:

```bash
npx wrangler deploy
```

배포가 끝나면 네이버 화면의 **소유확인** 버튼을 누른다.

### 사이트맵 제출

확인이 끝나면 왼쪽 메뉴에서:

- **요청 → 사이트맵 제출** → `sitemap.xml` 입력
- **요청 → 웹페이지 수집** → 아래 넷을 하나씩 넣는다 (수집이 빨라진다)
  - `https://myan.riger7070.workers.dev/tti`
  - `https://myan.riger7070.workers.dev/calc/samjae`
  - `https://myan.riger7070.workers.dev/calc/sinsal`
  - `https://myan.riger7070.workers.dev/calc/bonmyeong`

## 2. 구글 서치 콘솔

1. <https://search.google.com/search-console> 접속 → 구글 계정으로 로그인
2. **속성 추가** → **URL 접두어** 쪽을 고른다 (도메인 쪽은 DNS 를 만져야 한다)
3. `https://myan.riger7070.workers.dev` 입력

### 소유 확인

**HTML 파일** 방식을 고른다. `google1a2b3c4d.html` 같은 이름이 나온다.
네이버와 똑같이 이름만 넣으면 된다.

```toml
GOOGLE_VERIFY = "google1a2b3c4d.html"
```

```bash
npx wrangler deploy
```

배포 후 **확인** 을 누른다.

> 둘 다 등록한다면 `wrangler.toml` 에 두 줄을 함께 넣고 한 번만 배포해도 된다.

### 사이트맵 제출

왼쪽 메뉴 **Sitemaps** → `sitemap.xml` 입력 → 제출.

---

## 3. 잘 됐는지 보기

배포한 뒤 이렇게 확인한다.

```bash
curl https://myan.riger7070.workers.dev/robots.txt
```

소유 확인 파일이 제대로 나오는지 (이름은 실제로 받은 것으로 바꿔서):

```bash
curl https://myan.riger7070.workers.dev/naver1a2b3c4d.html
```

`naver-site-verification: naver1a2b3c4d.html` 이 나오면 된 것이다.

## 얼마나 걸리나

- **소유 확인**: 바로
- **사이트맵 읽어 가기**: 하루 이틀
- **검색 결과에 나타나기**: 네이버 1~3주, 구글 2~4주

새 사이트는 원래 느리다. 조바심 낼 일이 아니다.
`/tti` 는 날마다 내용이 바뀌므로 사이트맵에 `daily` 로 적어 두었다 —
자리를 잡으면 이쪽이 가장 자주 들어오는 문이 될 것이다.
