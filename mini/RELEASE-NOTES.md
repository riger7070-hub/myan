### 고친 것

**나갔다 들어올 때마다 다시 로그인하던 문제 (가장 중요)**

앱을 닫으면 로그인이 풀려서, 다시 여실 때마다 소개 화면부터 토스 인증까지 처음부터
거치셔야 했습니다. 로그인 정보를 앱이 꺼져도 남는 자리에 옮겼습니다. 이제 한 번
로그인하시면 그대로 이어집니다.

**엽전이 덜 돌아오던 문제**

풀이를 만들다 실패했을 때 가져간 만큼 돌려드리지 않던 곳이 넷 있었습니다
(오행 유형 테스트, 라이프패스 넘버, 토정비결풍 신년운세, 관상과 손금).
실패했을 때만 드러나는 문제라 눈에 잘 띄지 않았습니다. 이제 가져간 만큼 그대로
돌려드립니다.

**신호가 약한 곳에서 첫 화면에 갇히던 문제** — 지하철이나 엘리베이터에서 앱을 켜면
여는 화면에서 한참 멈춰 있었습니다. 확인이 늦으면 기다리지 않고 넘어갑니다.

**입력칸을 눌러도 반응이 없던 문제** — 생년월일이나 이름을 적을 수 없던 문제입니다.

**엽전 충전이 되지 않던 문제** — 상품 목록을 못 불러오던 것과, 충전 화면에 처음
들어갔을 때 "상품 없음"이 뜨던 것을 함께 고쳤습니다.

**결제를 취소하면 실패로 뜨던 문제** — 그만두신 것을 오류라고 알려 드리지 않습니다.

**광고**

- 광고가 아예 뜨지 않던 문제
- 광고를 보고 나서 "한 번 더" 할 길이 없던 문제
- 광고가 실패하면 왜 안 되는지 알려 드립니다

**AI 가 쓴 티가 나던 기호** — 풀이에서 걷어냈습니다. 같은 물음을 두 번 되묻지도
않습니다.

### 고친 것

**결과 화면이 뜨지 않던 문제 (가장 중요)**
풀이를 눌러도 불러오는 화면에서 넘어가지 않는 일이 있었습니다. 서버는 정상이었고
결과를 그리는 순간에만 오류가 나서, 오류 문구조차 없이 계속 기다리게 됐습니다.
모든 콘텐츠에 해당하던 문제로, 원인을 제거하고 같은 종류의 실수를 막는 검사를 추가했습니다.

**풀이가 늦게 나오던 문제**
AI가 답을 쓰기 전에 속으로 생각하는 단계를 끄지 않고 있었습니다. 14곳 모두 껐고,
45초가 넘으면 기다리게 두지 않고 알려 드립니다.

**뒤로가기를 누르면 앱이 꺼지던 문제**
화면 단계를 따라 한 칸씩 돌아가고, 첫 화면에서만 앱이 닫힙니다.

**출석 도장이 "처리에 실패했습니다"라고 뜨던 문제**

**주제별 운세·택일이 되지 않던 문제** — 화면이 보내는 값과 서버가 기다리는 값이 달랐습니다.

**결제**
- 상품 목록을 불러오지 못하던 문제
- 결제가 안 될 때 이유가 보이지 않던 문제

**내 정보**
- 이름·생년월일·성별이 저장되지 않던 문제
- 토스에서 받아온 정보가 화면에 채워지지 않던 문제

**관상·손금** — 사진이 크면 자동으로 줄여서 올립니다.

**이미지로 저장** — 눌러도 아무 일도 없던 문제.

**택일** — 날짜를 고르는 자리가 없던 문제.

**지난 기록** — 긴 풀이가 중간에 잘려 보이던 문제. 이제 전체를 보실 수 있습니다.
